# Demo 5: Deploying & Governing Agents in GitHub Enterprise

## What This Demo Shows

GitHub Enterprise (GHEC/GHES) gives administrators granular control over every Copilot capability — feature toggles, model selection, IP protection policies, content exclusions, audit logs, and seat management. This demo walks through the enterprise controls available to admins who need to deploy agentic AI responsibly.

## Why It Matters in the Talk

Enterprise adoption of agentic AI stalls when security and compliance teams can't answer: "Who authorized this? What did it do? Can we turn it off?" This demo answers all three questions — and shows that GitHub's governance story is a genuine competitive differentiator.

## Required Setup / Accounts / Tools

- GitHub Enterprise Cloud (GHEC) organization with admin access
- GitHub Copilot Business or Enterprise subscription at the org level
- Navigate to: **Org Settings → Copilot** and **Org Settings → Audit log**
- Optionally: Enterprise-level settings panel (requires Enterprise account/owner access)

## Demo Duration

**~7 minutes**

## Key Concepts Demonstrated

- Org-level Copilot feature toggles (coding agent, code review, Autofix, suggestions)
- IP protection: "Exclude from training" policy
- Content exclusions: files and paths Copilot cannot access
- Audit log: Copilot-related events
- Seat management and usage analytics
- Model management (Enterprise): pinning to specific foundation models

## Audience Takeaway

> "I can give my engineers full agentic AI capabilities while giving my security team the audit trail and policy controls they require. It's not a tradeoff."
