# Demo 1: Agentic vs. Assistive

## What This Demo Shows

A side-by-side comparison of completing the same task using assistive AI (Copilot inline chat in VS Code) versus agentic AI (GitHub Copilot coding agent via a GitHub issue). The contrast makes the conceptual shift visceral and concrete.

## Why It Matters in the Talk

The assistive-to-agentic shift is the central thesis of the workshop. This demo makes it tangible in the first five minutes — establishing the mental model that everything else in the session builds on.

## Required Setup / Accounts / Tools

- VS Code with GitHub Copilot extension (assistive side)
- GitHub repo with Copilot coding agent enabled (agentic side)
- Two tabs open: VS Code + GitHub.com
- The same task scoped for both approaches

## Demo Duration

**~5 minutes**

## Key Concepts Demonstrated

- Assistive mode: developer-in-the-loop at every step
- Agentic mode: developer defines task → agent executes → developer reviews
- What makes a task "agent-ready" vs. "IDE-ready"
- The agentic loop: observe → plan → act → verify

## Audience Takeaway

> "Assistive AI needs me for every decision. Agentic AI needs me for the first and last decision. Everything in between, the agent handles."
