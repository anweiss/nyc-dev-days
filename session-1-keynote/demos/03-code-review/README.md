# Demo 3: Copilot Code Review

## What This Demo Shows

Copilot code review analyzes a pull request and provides inline, actionable feedback — covering logic issues, security concerns, test gaps, and code quality. It works like requesting a human reviewer, but responds in seconds.

## Why It Matters in the Talk

Code review is a bottleneck in nearly every engineering team. Copilot accelerates it by catching the obvious issues before human reviewers even look — letting the team focus on architecture and intent.

## Required Setup / Accounts / Tools

- GitHub repository with Copilot code review enabled (org-level: **Settings → Copilot → Code review**)
- GitHub Copilot Business or Enterprise subscription
- A pull request already open in the demo repo — ideally the one the coding agent created in Demo 2
- The PR should have at least one reviewable issue (logic gap, missing error handling, security smell) for Copilot to catch
- Demo tip: Request the Copilot review before the talk so comments are pre-populated; you walk through them live

## Demo Duration

**~5 minutes**

## Key Concepts Demonstrated

- Requesting Copilot as a reviewer on a PR
- Inline review comments with severity ratings
- "Apply fix" one-click resolution
- Copilot's reasoning about the code change

## Audience Takeaway

> "Copilot caught a missing error case my teammate would have caught — but 30 seconds faster and without an async back-and-forth."
