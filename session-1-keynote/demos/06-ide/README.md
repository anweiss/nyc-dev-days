# Demo 6: IDE — VS Code & JetBrains

## What This Demo Shows

The deepest Copilot integration is in the IDE. This demo covers the full range of GitHub Copilot IDE capabilities: inline completions, inline chat, Copilot Edits (multi-file editing), and the Copilot Chat panel — in both VS Code and JetBrains (IntelliJ / PyCharm / etc.).

## Why It Matters in the Talk

The editor is where code actually gets written. Showing the breadth and depth of Copilot's IDE integration reinforces that Copilot isn't a web-only feature — it's deeply embedded in the tools developers use every day.

## Required Setup / Accounts / Tools

**VS Code:**
- VS Code 1.90+ installed
- GitHub Copilot extension installed and enabled: `ext install GitHub.copilot`
- GitHub Copilot Chat extension: `ext install GitHub.copilot-chat`
- Signed in to GitHub in VS Code

**JetBrains:**
- IntelliJ IDEA 2024.1+ (or PyCharm / WebStorm / etc.)
- GitHub Copilot plugin installed: **Plugins → Marketplace → GitHub Copilot**
- Signed in to GitHub in the IDE

**Both:**
- Demo repo cloned locally and open in the IDE
- Active GitHub Copilot subscription

## Demo Duration

**~6 minutes** (VS Code: ~4 min, JetBrains: ~2 min)

## Key Concepts Demonstrated

- **Inline completions:** Tab-to-accept multi-line suggestions
- **Inline chat (`Cmd+I` / `Alt+\`):** Describe a change, see a diff, accept/discard
- **Copilot Edits:** Multi-file editing mode — describe a cross-file change
- **Copilot Chat panel:** Ask questions about the codebase, get explanations, generate tests
- **JetBrains parity:** Same capabilities, different UI

## Audience Takeaway

> "Copilot isn't just tab-completion anymore. It's a pair programmer that understands my whole project and can make changes across files at once."
