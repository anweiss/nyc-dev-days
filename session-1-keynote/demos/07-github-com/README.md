# Demo 7: Copilot on GitHub.com

## What This Demo Shows

GitHub.com has its own native Copilot experience: Copilot Chat that understands your repositories, PR summary generation, and issue triage assistance. This demo shows how Copilot augments collaboration and project management workflows directly on the GitHub platform — no IDE required.

## Why It Matters in the Talk

Developers spend significant time on GitHub.com reviewing PRs, triaging issues, and understanding unfamiliar codebases. Copilot on GitHub.com accelerates all of these workflows by bringing contextual AI to where collaboration already happens.

## Required Setup / Accounts / Tools

- GitHub account with Copilot subscription
- Navigate to github.com in a browser (logged in as demo account)
- A repository with some history (the demo repo works great)
- An open pull request for the PR summary demo
- Copilot enabled on the org: **Org Settings → Copilot → Enable**

## Demo Duration

**~4 minutes**

## Key Concepts Demonstrated

- **Copilot Chat on GitHub.com:** Repo-aware conversational AI
- **PR Summary generation:** Auto-drafted PR description from the diff
- **Issue drafting:** Structured issue from a rough description

## Audience Takeaway

> "Copilot on GitHub.com knows my repository. I can ask it anything about my code without leaving the browser."
