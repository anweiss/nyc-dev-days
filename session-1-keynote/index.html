A Full Coding Agent in Your Terminal

# Find sprint work via GitHub MCP

  • GitHub MCP built in — issues, PRs, branches via natural language
  • Shift+Tab to cycle modes: ask → plan → autopilot

  • /model & /fleet — switch models or parallelize subagents

Agent Readiness

Writing Great Issues = Writing Great Agent Prompts

✓ Good for the Agent
  • Bounded scope — one endpoint, one migration, one component
  • Measurable success — tests pass, API contract matches spec
  • Established tech stack — Express, Jest, SQLite already in use
  • No ambiguous architecture — the right pattern already exists in the repo
✗ Keep for the Human
  • "Improve performance" — no clear success metric
  • "Refactor the whole auth system" — too broad, architectural
  • Cross-cutting changes with organizational buy-in required
  • Anything requiring stakeholder judgment calls
# PDP-001 — a well-scoped agent issue
"Add GET /products/:id endpoint. Return name, price, description, stock.
Follow existing route patterns in src/routes/. Add Jest tests."

Demo 4

From Vulnerability to Fix in One Click

GHAS CodeQL flags XSS in app.js (CWE-79). Copilot Autofix proposes the fix. Explanation included.

// ❌ Vulnerable — innerHTML sink
productEl.innerHTML = req.query.name;

// ✅ Autofix — safe replacement
productEl.textContent = req.query.name;
  • GHAS CodeQL detects: XSS, SQLi, hardcoded credentials, path traversal
  • Copilot Autofix generates an actual code change — not "sanitize your inputs"
  • Fix includes full explanation of the vulnerability and attack vector closed
~70%
of GHAS alerts resolvable automatically with Autofix

Copilot That Speaks Your Team's Language

Custom extensions surface your team's knowledge inside Copilot Chat — invoked with @extension-name.

# Alex during on-call shift

if a bad deploy hits production?

# Extension returns the runbook instantly
→ Step 1: gh workflow run rollback.yml …
  • Agent extensions — full LLM reasoning loop, call external APIs, take actions

Demo 6

The Editor: Completions → Chat → Multi-File Edits

VS Code & JetBrains: three levels of AI assistance across the spectrum.

  • Tab Completions — multi-line, context-aware; understands workspace patterns
  • Inline Chat (Cmd+I) — describe a change in English, see the diff, accept or discard
  • Copilot Edits — one prompt, diffs across all relevant files simultaneously
  • JetBrains parity — IntelliJ, PyCharm, GoLand, Rider — same capabilities
# Inline Chat prompts Alex uses today
"Add input validation to this route handler"
"Write Jest tests for the new /products/:id endpoint"
"Refactor to use async/await throughout"
